## Same measure name, different definition

| Measure | Model | DAX |
|---|---|---|
| Cancel Refunds | Ops | `SUM(Cancels[CustomerRefund])` |
| Cancel Refunds | Finance | `SUM('Fact Cancels Gen3'[RefundAmount])` |
| Claims Paid | Ops | `SUM(Claims[ClaimAmount])` |
| Claims Paid | Reporting | `SUM('Fact Claims'[Claim Amount])` |
| Contracts | Ops | `COUNTROWS(Contracts)` |
| Contracts | Finance | `DISTINCTCOUNT('Fact Contracts'[fxContractId])` |
| Contracts | Reporting | `DISTINCTCOUNT('Fact Contracts'[fxContractId])` |
| Coverage Cost | Finance | `SUM('Fact Contracts'[CoverageCost])` |
| Coverage Cost | Reporting | `SUM(Contracts[CoverageCost])` |

## Dimensions kept once per model

- **contract**: `Ops:legacy_ops.vw_dim_contracts`, `Reporting:legacy_reporting.vw_dim_contracts`
- **contract facts**: `Finance:legacy_finance.vw_fact_contracts`, `Reporting:legacy_reporting.vw_fact_contracts`
- **product**: `Ops:legacy_ops.vw_dim_products`, `Reporting:legacy_reporting.vw_dim_product`

## The trap in one line

Ops `Contracts[Producers]` is the selling dealer; Reporting `Producers[Producer]` is the provider
entity. A report filter on the wrong one returns zero rows without an error.

The modern platform replaces all three with one shared conformed model (`semantic/`).
